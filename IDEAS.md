# Effect steal SMP


## Main idea
___
New block: alchemy table

kill player => get 5  player heads => Trade the 5 heads for a permanent ==bonus effect== using ==the alchemy table==
Die yourself => get a random permanent negative effect


## Bonus effects
___
Possible effects:

| Effect | max-lvl |
|-------|---------|
| Dolphin's grace | 1 |
| Fire res | 1 |
| Haste | inf. |
| Health boost | 3 |
| jump boost | Inf. |
| Speed | Inf. |
| Resistance | 2 |
| Strength | Inf. |
| Conduit Power | 1 |
| Master of the Evil | 3 |
| Chemical Bliss | 3 |

These effects are permanently applied. In the alchemy table you can select a permanent effect and apply / upgrade it by using the dedicated buttons.

### Master of the Evil
LVL 1: Creepers, Zombies,Skeletons and Spiders are passive

LVL 2: Every hostile mob is passive

LVL 3: Wither and warden are also passive

### Chemical bliss
LVL 1: Buff the potion durations you brew (``3:00`` -> ``5:00`` | ``8:00`` -> ``12:00`` | ``1:30`` -> ``5:00``)

LVL 2: Increase (+) potion lvl by 1 (eg: ``Strength I`` -> ``Strength II``)

LVL 3: More duration (``3:00`` -> ``8:00`` | ``8:00`` -> ``16:00`` | ``1:30`` -> ``8:00``) + Poison/Instand damage lvl increase

## Negative effects
___

Possible effects:
- weakness
- slowness
- mining fatigue

When the effect is already applied, the level increases instead.

These effects can be cleared by:
- Eating an enchanted golden apple. (clears the last applied effect)
- Spending 5 player heads in the alchemy table to clear a chosen effect

## Alchemy table
___
A custom block that replaces the brewing stand. Craftable using a brewing stand, copper blocks, planks and a diamond.

The gui is split into 2 sections:

On the left, you have the brewing stand, and a button that expands a recipe section. This section displays all vanilla recipes for potions incase you forgot.

On the right you have the permanent effects. You can click on the effects to view what they do, their current and max level. This also selects it. Next you can click on a start ritual button which will exit the gui and show that you need to apply 5 player heads plus 3 lapis.
